## 怎么跑

```bash
pnpm install
pnpm build
pnpm check
```

## 门禁

提交前都要绿：

```bash
pnpm check
cd docs-site && pnpm doc && pnpm build
```

## 红线

- deepseek 插件是哑管道：不往里加重试 / 熔断 / 缓存 / 消费方策略，降级决策全在调用方
