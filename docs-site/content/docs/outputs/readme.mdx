# gwb-nas-suite

**本页回答**：`gwb-nas-suite` 是什么、怎么装、怎么确认装好了、文档在哪。

## 是什么

绿联 NAS 监控与日常资讯的 gwb 插件仓（仓根是 pnpm workspace，三个插件在 `plugins/`）：

| 插件 | 包名 | 做什么 |
| --- | --- | --- |
| deepseek | `@godcreator/gwb-deepseek` | 整个工作台共用的 DeepSeek 调用入口：一条 `deepseek.chat`，API key 只存在这个插件的设置里，每次调用都记账 |
| news-links | `@godcreator/gwb-news-links` | 资讯精选阅读器：取 FreshRSS 与邮件的增量，经 DeepSeek 挑出值得看的链接 |
| nas-board | `@godcreator/gwb-nas-board` | NAS 体检看板：经 SMB 拉绿联 NAS 每天的定案 JSON，在工作台的窗格里画出来 |

NAS 侧的数据生产与部署在 ugreen-nas-config（单元 26091409bfn）。deepseek 已实现；news-links 与 nas-board 还是 devkit 模板的形状，
设计与验收清单在文档站未来区的实施方案（`docs-site/content/future/spec/`）。

## 怎么装

逐个装进 home：`plugin-manager.install {"pkg":"<上表包名>"}`。安装不会顺带装 peer：deepseek 要 home 里有命令总线、设置、数据三个插件，
news-links 与 nas-board 要有命令总线与外壳；缺的在 `plugin-manager.list` 的 `unmetPeers` 里看得到。

## 怎么确认装好了

`plugin-manager.list` 里三个包的条目都在运行；`deepseek.usage` 回汇总（不花钱，不发请求），`nas-board.ping`、`news-links.ping` 回插件名与时刻。

## 文档

`docs-site/` 是文档站（god-docsite + docfirst），由 gwb 工作台托管开发服务：`docsite.site.add {"dir":"<站目录>"}`，地址看 `docsite.site.list`。
这份 README 是生成物，正本是 `docs-site/content/docs/outputs/readme.mdx`。
