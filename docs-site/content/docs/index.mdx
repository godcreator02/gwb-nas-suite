# gwb-nas-suite

**本页回答**：`gwb-nas-suite` 是什么、边界在哪、从哪一页开始读。

## 是什么

这是 NAS 监控与资讯消费的 gwb 插件仓：仓根只是 workspace 根目录，三个插件在 `plugins/`——`deepseek`（模型命令管道）、`nas-board`（NAS 体检看板）、`news-links`（资讯精选阅读器）。NAS 侧的数据生产与部署在 ugreen-nas-config（单元 26091409bfn），这个仓只有消费端；两边的契约是 NAS 每日归档的定案 JSON 与 FreshRSS / mail-archiver 的既有 API。

deepseek 已经实现；news-links 与 nas-board 还是 devkit 模板的形状，设计与验收清单在未来区的实施方案页（[nas-board](/future/spec/nas-board)、[news-links](/future/spec/news-links)）。往哪儿去见 [未来](/future/overview)。
